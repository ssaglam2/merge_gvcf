This file contains practical examples for using the GVCF pipeline.

===============================================================================
BASIC USAGE
===============================================================================

1. SETUP YOUR DIRECTORY STRUCTURE:
   
   Your_Project/
   ├── gvcf/                              # Put your GVCF files here
   │   ├── sample1.hard-filtered.gvcf.gz
   │   ├── sample2.hard-filtered.gvcf.gz
   │   └── sample3.hard-filtered.gvcf.gz
   └── GVCF_Pipeline_Solution/            # Copy this folder here
       ├── gvcf_filter_merge.sh
       ├── backup_merge_only.sh
       ├── README.md
       └── USAGE_EXAMPLES.txt

2. INSTALL DEPENDENCIES (in WSL):
   
   sudo apt update
   sudo apt install bcftools tabix parallel

3. RUN THE PIPELINE:
   
   cd GVCF_Pipeline_Solution
   bash gvcf_filter_merge.sh

TROUBLESHOOTING EXAMPLES
===============================================================================

PROBLEM: "No GVCF files found"
SOLUTION:
   # Check your file location
   ls gvcf/*.gvcf.gz
   ls gvcf/*.g.vcf.gz
   
   # Make sure files are in the right place
   mkdir -p gvcf
   cp /path/to/your/files/*.gvcf.gz gvcf/

PROBLEM: "bcftools not found"
SOLUTION:
   # Install in WSL
   sudo apt update
   sudo apt install bcftools tabix parallel

PROBLEM: Pipeline fails during merge
SOLUTION:
   # Use the backup merge script
   bash backup_merge_only.sh

PROBLEM: Memory issues
SOLUTION:
   # Edit the script to reduce parallel jobs
   nano gvcf_filter_merge.sh
   # Change: MAX_PARALLEL_JOBS=1

===============================================================================
INTEGRATION WITH OTHER TOOLS
===============================================================================

AFTER PIPELINE COMPLETION, YOU CAN:

1. CONVERT TO PLINK FORMAT:
   plink2 --vcf filtered_merged_output/merged_pass_chr1-22.vcf.gz \
          --make-bed \
          --out my_dataset

2. BASIC STATISTICS:
   bcftools stats filtered_merged_output/merged_pass_chr1-22.vcf.gz > stats.txt

3. EXTRACT SAMPLE NAMES:
   bcftools query -l filtered_merged_output/merged_pass_chr1-22.vcf.gz > samples.txt

4. COUNT VARIANTS PER CHROMOSOME:
   bcftools query -f '%CHROM\n' filtered_merged_output/merged_pass_chr1-22.vcf.gz | sort | uniq -c

===============================================================================
CUSTOMIZATION EXAMPLES
===============================================================================

TO INCLUDE SEX CHROMOSOMES:
   # Edit gvcf_filter_merge.sh
   # Change the CHROMOSOMES line to:
   CHROMOSOMES="chr1,chr2,chr3,chr4,chr5,chr6,chr7,chr8,chr9,chr10,chr11,chr12,chr13,chr14,chr15,chr16,chr17,chr18,chr19,chr20,chr21,chr22,chrX,chrY"

TO PROCESS ONLY SPECIFIC CHROMOSOMES:
   # Edit gvcf_filter_merge.sh
   # Change the CHROMOSOMES line to:
   CHROMOSOMES="chr1,chr2,chr3"

TO USE DIFFERENT INPUT DIRECTORY:
   # Edit gvcf_filter_merge.sh
   # Change the INPUT_DIR line to:
   INPUT_DIR="my_gvcf_files"

===============================================================================
QUALITY CONTROL CHECKS
===============================================================================

VERIFY YOUR RESULTS:

1. CHECK SAMPLE COUNT:
   bcftools query -l filtered_merged_output/merged_pass_chr1-22.vcf.gz | wc -l
   # Should match your input file count

2. CHECK CHROMOSOMES:
   bcftools view -h filtered_merged_output/merged_pass_chr1-22.vcf.gz | grep "##contig"
   # Should only show chr1-22 (or 1-22)

3. CHECK FILTER STATUS:
   bcftools view -H filtered_merged_output/merged_pass_chr1-22.vcf.gz | cut -f7 | sort | uniq
   # Should only show "PASS"

4. BASIC STATISTICS:
   bcftools stats filtered_merged_output/merged_pass_chr1-22.vcf.gz | head -20
