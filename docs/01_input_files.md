# Input Files

The gVCF processing pipeline requires specific input files formatted correctly.

## Primary Input: gVCF Files

*   **Format:** The primary input consists of multiple genomic VCF (gVCF) files. These files should be gzipped (ending in `.gz`).
*   **Location:** All input gVCF files must be placed in the same directory from which you intend to run the `run_gvcf_pipeline.sh` script.
*   **Naming Convention (for automatic list generation):**
    *   The script, by default, looks for files ending with the pattern `*.hard-filtered.gvcf.gz` to automatically generate the `gvcf_list.txt` file if it's not already present.
    *   If your files have a different naming pattern, you should either:
        1.  Modify the `ls` command in `run_gvcf_pipeline.sh` (Step 1 of the script).
        2.  Or, manually create a `gvcf_list.txt` file yourself, listing one input gVCF filename per line.
*   **Chromosome Naming:**
    *   The pipeline is currently configured to work with chromosome names that have a "chr" prefix (e.g., `chr1`, `chr10`, `chrX`).
    *   If your gVCFs use a different convention (e.g., `1`, `10`, `X` without the "chr" prefix), you will need to modify Step 0 in `run_gvcf_pipeline.sh` where `standard_chroms.txt` is created. Specifically, remove the `| sed 's/^/chr/'` part.
*   **Indexing:** Input gVCFs do **not** need to be pre-indexed. The individual filtering step (Step 3 of the script) will index the intermediate filtered gVCFs before they are passed to `bcftools merge`.

## Helper Files (Generated by the script)

The script will generate or use the following helper files:

*   **`gvcf_list.txt`:**
    *   A plain text file listing the names of all input gVCF files, one filename per line.
    *   If this file does not exist when the script starts, the script will attempt to create it using `ls *.hard-filtered.gvcf.gz > gvcf_list.txt`.
    *   If you have a different naming pattern for your gVCFs, or if you want to process a specific subset, you can create this file manually.
*   **`standard_chroms.txt`:**
    *   A plain text file listing the chromosomes to be included in the analysis, one chromosome name per line.
    *   The script generates this file by default to include `chr1` through `chr22`.
    *   This file is used by `bcftools view -t ^standard_chroms.txt` to filter each gVCF.

**Example `gvcf_list.txt`:**
```
sampleA.hard-filtered.gvcf.gz
sampleB.hard-filtered.gvcf.gz
sampleC.hard-filtered.gvcf.gz
```

**Example `standard_chroms.txt` (as generated by the script):**
```
chr1
chr2
chr3
...
chr22
```
